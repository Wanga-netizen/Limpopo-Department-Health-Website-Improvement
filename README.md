# Limpopo Department of Health Website Improvement

## Project Overview

This project was completed as part of an academic collaboration to improve the existing website of the Limpopo Department of Health.

The project focused on improving the website's user interface, redesigning existing pages, making the website responsive across different screen sizes and improving navigation to create a more accessible and user-friendly experience.

**Original Website:** https://www.ldoh.gov.za/

## Project Objectives

- Improve the overall user interface and website appearance.
- Redesign existing web pages to improve their layout and presentation.
- Implement responsive design for different screen sizes and devices.
- Improve website navigation and the accessibility of information.
- Enhance the overall user experience.

## Technologies Used

- HTML
- CSS
- JavaScript

## Collaboration

This was a collaborative academic project completed by two Computer Science students who contributed equally to the website improvements, design changes and development work.

## Project Type

Academic Project | Collaborative Front-end Development
